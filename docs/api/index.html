Eyes of Argus

A browser extension that marks YouTube channels, social media accounts and websites that use AI and/or are owned by private equity.

Works on YouTube, X, Reddit, Instagram, TikTok, Twitch and Facebook, and on Google, Bing and DuckDuckGo results (a result marks its whole website). Right-click a channel name or video → Eyes of Argus → mark it. Works offline, with no account. Optional community sync through a tiny self-hosted server (see server/README.md).

Install

Firefox (for testing)

  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on… and pick eyes-of-argus-firefox-0.5.0.zip
  3. Reload any open YouTube tabs

Temporary add-ons disappear when Firefox restarts. To keep it installed, upload the zip to https://addons.mozilla.org/developers/ as "On your own" (unlisted). Signing is free and you get a signed .xpi you can install permanently.

Chrome / Edge / Brave / Opera

  1. Unzip eyes-of-argus-chrome-0.5.0.zip into a folder
  2. Open chrome://extensions (or edge://extensions), turn on Developer mode
  3. Click Load unpacked and pick the folder

Using it

  • Right-click any link on any website, a channel name, a video thumbnail, a search result, or an empty spot on a page
  • Mark as AI channel / Mark as private-equity owned (a channel can be both)
  • Not AI / Not PE-owned: you disagree. This hides community/shared marks for you and votes against them
  • Clear: back to no opinion
  • Marked channels get an AI / PE badge and tinted name everywhere on YouTube
  • Click the toolbar icon for settings: badges, tinting, fading marked videos, your list of marks

Community sync

Turn it on in settings and enter your sync server address. Votes are queued while you're offline and sent when you're back online. The community list is cached for offline use.

Sharing marks without a server

  • Export marks in settings creates a JSON file you can send to others, who Import it
  • Or host that file somewhere static and free (e.g. a GitHub repo) and others paste its raw URL into Shared list. It updates twice a day when online. Your own marks always override it.

List format:

{ "app": "eyes-of-argus", "version": 1,
  "channels": {
    "@somechannel": { "ai": true, "pe": false, "name": "Some Channel" },
    "UCxxxxxxxxxxxxxxxxxxxxxx": { "ai": false, "pe": true, "name": "Other" }
  } }

Building from source

Edit files in src/, then run python build.py. Output goes to dist/.

Development

npm install && (cd server && npm install)
python build.py      # builds dist/
npm test             # 73 tests, including a local sync server
npm run test:browser # loads the Chrome build into a real Chrome
npm run lint         # ESLint + Mozilla's add-on linter
npm run docs         # API reference in docs/api

server/src/admin.js

Moderation dashboard of the sync server.

GET /admin serves one self-contained page (no external resources). Everything it does goes through the small API below, and every API call needs the admin token as Authorization: Bearer <ADMIN_TOKEN>; the page itself contains no data.

Route What it does
GET /admin the dashboard page
GET /admin/api/channels ?q=<search>&shown=1 → up to 100 entries with tallies and overrides
POST /admin/api/override {key, ai, pe, note} with ai/pe: 1 = always show, 0 = never show, null = let votes decide
POST /admin/api/purge {key} → delete every vote for that entry
POST /admin/rebuild recount everything

server/src/index.js

Eyes of Argus sync server (Cloudflare Worker + D1 + KV).

Route What it does
GET /config puzzle difficulty and thresholds
GET /snapshot.json the community list (ETag, edge cache)
POST /register {secret, nonce} → {id}: anonymous install, proof of work
POST /votes {secret, votes:[{k,f,v,name}], replace?}
POST /forget {secret}: delete all of this install's votes and the install
GET /admin moderation dashboard (see admin.js); its API needs Authorization: Bearer <ADMIN_TOKEN>
POST /admin/rebuild recount everything
cron (15 min) recount changed channels, patch the snapshot

Abuse resistance (see server/README.md, "Threat model"): POSTs only from extensions or non-browser clients; daily limits per install and per network (IPv6 grouped by /56); new installs carry no weight for their first days; at most MAX_PER_NET votes per channel count from installs registered on the same network.

src/background.js

Background script of Eyes of Argus.

Runs as an event page in Firefox and as a service worker in Chromium; either can be stopped at any time and restarted by an event, so every listener is registered synchronously at the top level and all state lives in storage.local.

Responsibilities:

  1. The right-click menu on YouTube.
  2. The only writer of your marks, the vote queue and sync settings. The content script and the settings page send messages (see Argus.MSG); every change runs through one promise chain (serial), so two tabs can never overwrite each other's change.
  3. Community sync: anonymous registration (proof of work), sending queued votes, downloading the community list. Upload and download fail independently, so the last community list always keeps working offline.
  4. The optional subscribed shared list (any static JSON file).

Storage keys (all in storage.local):

syncReplace background true → next upload replaces all your votes on the server
sync background {enabled, server}

pendingForget background {server, secret} "delete my votes" still to be sent

src/content.js

Content script of Eyes of Argus (top frame of every supported site).

Site-specific knowledge lives in platforms.js; this file is generic. Two jobs:

  1. Show marks. Every account link (or search result) on the page gets a data-argus="ai pe" attribute and its card a data-argus-card attribute; content.css turns those into badges, tinted names and faded cards. Setting attributes is the only DOM work, so the cost on the page stays tiny.
  2. Resolve right-clicks. When a menu item is chosen, work out which account or website was right-clicked and ask the background to change it (the background is the only part that writes marks; see background.js).

Where a key's state comes from, highest priority first: your own mark (yes / "not") → the subscribed shared list → the community list.

src/options.js

Settings page of Eyes of Argus.

Reads everything straight from storage.local and re-renders when it changes. It never writes marks, the vote queue or sync settings itself: those changes are sent to the background (the single writer, see background.js) as Argus.MSG messages. Display toggles and the shared-list URL are the only keys written here.

Permission prompts (permissions.request) must run directly inside a click, before any other await, or browsers refuse them; every handler below keeps that order.

src/platforms.js

Per-site adapters for the content script.

content.js is generic; everything a site needs is described here by one adapter:

field meaning
id platform name
test(host) does this adapter handle the page's hostname?
owns(key) is this key shown on this site? (keeps the lookup map small)
linkSel CSS selector for links that can point at an account / site
keyOf(a) canonical key for a link, or null
nameOf(a,key) optional display name (default: the link text)
badgeEl(a) optional element that carries the badge (default: the link, if text-only)
cardSel optional selector of the "card" around a post / result (for fading, and right-clicks)
boxSel optional wider selector used only for right-clicks (default cardSel)
guessFromCard right-click anywhere in a card marks the card's first account link
ignoreSel optional: DOM changes inside this are ignored (e.g. the video player)
pageTarget() optional: the account the current page belongs to {key, name, box?}
enrich(r,ctx) optional: add extra data to a resolved right-click target

Selectors for third-party sites can go stale when those sites change their markup; the worst case is a missing badge or "No account found here", never a wrong mark: every key still has to pass Argus.normalizeKey.

Exposed as the frozen global ArgusPlatforms.

src/shared.js

Shared helpers for every part of Eyes of Argus.

Loaded first in every context:

  • the YouTube content script (manifest.content_scripts),
  • the background (Firefox event page via background.scripts, Chromium service worker via importScripts),
  • the settings page (<script> tag),
  • the Cloudflare Worker (import '../../src/shared.js'), so that client and server agree on what a valid channel key is and how proof-of-work is checked.

Nothing here touches the DOM or extension APIs, so it is safe in all of them. Everything is exposed on one frozen global, globalThis.Argus.
