The Eyes of Argus

A browser extension that marks YouTube channels that use AI and/or are owned by private equity. Right-click a channel name or video → The Eyes of Argus → mark it. Works offline, with no account. Optional community sync through a tiny self-hosted server (see server/README.md).

Install

Firefox (for testing)

  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on… and pick eyes-of-argus-firefox-0.2.0.zip
  3. Reload any open YouTube tabs

Temporary add-ons disappear when Firefox restarts. To keep it installed, upload the zip to https://addons.mozilla.org/developers/ as "On your own" (unlisted). Signing is free and you get a signed .xpi you can install permanently.

Chrome / Edge / Brave / Opera

  1. Unzip eyes-of-argus-chrome-0.2.0.zip into a folder
  2. Open chrome://extensions (or edge://extensions), turn on Developer mode
  3. Click Load unpacked and pick the folder

Using it

  • Right-click a channel name, a video thumbnail, or anywhere on a watch/channel page
  • Mark as AI channel / Mark as private-equity owned (a channel can be both)
  • Not AI / Not PE-owned: you disagree. This hides community/shared marks for you and votes against them
  • Clear: back to no opinion
  • Marked channels get an AI / PE badge and tinted name everywhere on YouTube
  • Click the toolbar icon for settings: badges, tinting, fading marked videos, your list of marks

Community sync

Turn it on in settings and enter your sync server address. Votes are queued while you're offline and sent when you're back online. The community list is cached for offline use.

Sharing marks without a server

  • Export marks in settings creates a JSON file you can send to others, who Import it
  • Or host that file somewhere static and free (e.g. a GitHub repo) and others paste its raw URL into Shared list. It updates twice a day when online. Your own marks always override it.

List format:

{ "app": "eyes-of-argus", "version": 1,
  "channels": {
    "@somechannel": { "ai": true, "pe": false, "name": "Some Channel" },
    "UCxxxxxxxxxxxxxxxxxxxxxx": { "ai": false, "pe": true, "name": "Other" }
  } }

Building from source

Edit files in src/, then run python build.py. Output goes to dist/.

server/src/index.js

The Eyes of Argus sync server (Cloudflare Worker + D1 + R2).

Route What it does
GET /config puzzle difficulty and thresholds
GET /snapshot.json the community list (ETag, edge cache)
POST /register {secret, nonce} → {id}: anonymous install, proof of work
POST /votes {secret, votes:[{k,f,v,name}], replace?}
POST /forget {secret}: delete all of this install's votes and the install
POST /admin/rebuild Authorization: Bearer <ADMIN_TOKEN>: recount everything
cron (15 min) recount changed channels, patch the snapshot

Abuse resistance (see server/README.md, "Threat model"): POSTs only from extensions or non-browser clients; daily limits per install and per network (IPv6 grouped by /56); new installs carry no weight for their first days; at most MAX_PER_NET votes per channel count from installs registered on the same network.

src/background.js

Background script of The Eyes of Argus.

Runs as an event page in Firefox and as a service worker in Chromium; either can be stopped at any time and restarted by an event, so every listener is registered synchronously at the top level and all state lives in storage.local.

Responsibilities:

  1. The right-click menu on YouTube.
  2. The only writer of your marks, the vote queue and sync settings. The content script and the settings page send messages (see Argus.MSG); every change runs through one promise chain (serial), so two tabs can never overwrite each other's change.
  3. Community sync: anonymous registration (proof of work), sending queued votes, downloading the community list. Upload and download fail independently, so the last community list always keeps working offline.
  4. The optional subscribed shared list (any static JSON file).

Storage keys (all in storage.local):

syncReplace background true → next upload replaces all your votes on the server

src/content.js

Content script of The Eyes of Argus (runs on youtube.com, top frame only).

Two jobs:

  1. Show marks. Every channel link on the page gets a data-argus="ai pe" attribute and its video card a data-argus-card attribute; content.css turns those into badges, tinted names and faded cards. Setting attributes is the only DOM work, so the cost on YouTube stays tiny.
  2. Resolve right-clicks. When a menu item is chosen, work out which channel was right-clicked and ask the background to change it (the background is the only part that writes marks; see background.js).

Where a channel's state comes from, highest priority first: your own mark (yes / "not") → the subscribed shared list → the community list.

src/options.js

Settings page of The Eyes of Argus.

Reads everything straight from storage.local and re-renders when it changes. It never writes marks, the vote queue or sync settings itself: those changes are sent to the background (the single writer, see background.js) as Argus.MSG messages. Display toggles and the shared-list URL are the only keys written here.

Permission prompts (permissions.request) must run directly inside a click, before any other await, or browsers refuse them; every handler below keeps that order.

src/shared.js

Shared helpers for every part of The Eyes of Argus.

Loaded first in every context:

  • the YouTube content script (manifest.content_scripts),
  • the background (Firefox event page via background.scripts, Chromium service worker via importScripts),
  • the settings page (<script> tag),
  • the Cloudflare Worker (import '../../src/shared.js'), so that client and server agree on what a valid channel key is and how proof-of-work is checked.

Nothing here touches the DOM or extension APIs, so it is safe in all of them. Everything is exposed on one frozen global, globalThis.Argus.
