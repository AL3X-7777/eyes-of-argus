(async) rebuild(env) → {Promise.<{changed: number, total: number}>}

Recounts channels that need it and republishes the community list.

The database is the source of truth: each channel row stores its published entry (entry, NULL when not shown). The list in KV is only a copy of those rows, written whenever one of them changed, so a crash or a stale KV read can't lose anything:

  • at most MAX_PER_RUN channels per run (free plan: 50 database queries per run);
  • a channel's dirty flag is only cleared if its rev is unchanged, so a vote that arrives during the recount keeps the channel queued;
  • a stale marker is set together with the row updates and cleared only after the list was written, so an interrupted run is finished by the next one.
